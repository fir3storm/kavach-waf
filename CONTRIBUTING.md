# Contributing to Kavach WAF

Thank you for your interest in contributing to Kavach WAF! This document provides guidelines for contributing to the project.

## 🙏 Code of Conduct

This project follows the ancient Indian principle of **"Vasudhaiva Kutumbakam"** (the world is one family). Be respectful, helpful, and constructive in all interactions.

## 🚀 Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/kavach-waf.git`
3. Create a branch: `git checkout -b feature/my-feature`
4. Make your changes
5. Run tests: `npm test`
6. Commit: `git commit -m "Add feature"`
7. Push: `git push origin feature/my-feature`
8. Open a Pull Request

## 🧪 Testing

All contributions must include tests:

```bash
# Run tests
npm test

# Run with coverage
npm run test:coverage
```

## 📝 Commit Guidelines

- Use clear, descriptive commit messages
- Reference issues when applicable: "Fix #123: Add bot detection"
- Keep commits focused and atomic

## 🎨 Code Style

- Follow existing code patterns
- Use meaningful variable names
- Add comments for complex logic
- Keep functions small and focused

## 🏷️ Naming Conventions

When adding new features, consider using Sanskrit-inspired names:
- Security features: Agni (fire), Vayu (wind), Varun (water)
- Protection: Kavach (armor), Raksha (protection)
- Detection: Drishti (vision), Jnana (knowledge)

## 📚 Documentation

Update documentation for any API changes:
- README.md for user-facing changes
- Inline comments for code changes
- JSDoc for function documentation

## 🐛 Bug Reports

When reporting bugs, include:
- Steps to reproduce
- Expected behavior
- Actual behavior
- Node.js version
- Operating system

## 💡 Feature Requests

Feature requests are welcome! Please:
- Describe the use case
- Explain why it would be useful
- Consider how it fits the project's philosophy
